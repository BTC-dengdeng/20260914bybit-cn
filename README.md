<h2 style="font-size:27px;line-height:1.5">六、什麼是「淨入金」？提領會影響獎勵嗎？</h2>

<p><strong>很多新戶看到「Deposit」就以為只要把錢轉進 Bybit 一次就完成，但部分任務實際計算的是 Net Deposit／淨入金。</strong></p>

<p>常見概念可以理解成：</p>

<p><strong>活動期間淨入金 = 活動期間符合條件的入金 − 活動期間提領出去的資產</strong></p>

<p>例如：</p>

<ul>
<li>你在活動期間入金 1,000 USDT；</li>
<li>之後又提領 400 USDT；</li>
<li>如果該任務採用淨入金邏輯，淨入金可能只剩約 600 USDT。</li>
</ul>

<p>因此，如果任務要求維持 1,000 USDT 淨入金，你在任務完成以前把部分資金提出，可能導致任務不再達標。</p>

<p><strong>是否採用淨入金、計算期間以及哪些入金方式計入，最終都要以該任務頁面的條款為準。</strong></p>

<hr style="border:none;border-top:1px solid #ddd;margin:36px 0">

<h2 style="font-size:27px;line-height:1.5">九、Bybit Bonus 領到後可以直接提領嗎？</h2>

<p>常見需要注意的地方：</p>

<ul>
<li>獎勵可能需要手動 Claim；</li>

<li>Bonus 本身可能不可直接提領；</li>
<li>部分獎勵到期後會自動失效；</li>
<li>提領資產可能影響未完成的新戶任務；</li>
<li>不同活動的 Bonus 規則不完全相同。</li>
</ul>

<p>因此看到「已獲得 100 USDT Bonus」時，不要直接理解成「帳戶多了 100 USDT 可以立刻提現」。</p>
